# 🧾 Bill Buddy - Your Handy Bill Generator
Note - Currently this application is modifies for Stationary Shops.
Bill Buddy is a simple Android application that helps you generate bills quickly and easily. Perfect for small businesses, freelancers, or anyone who needs to create invoices on the go!
- To modify app for your usage contact Developer - **dhyeyp254@gmail.com**
## 🚀 Features

* **Easy Item Selection:**
    * Choose from a predefined list of items using a dropdown menu (Spinner).
    * Easily add new items to your list for future use (if you implement this feature).
* **Quantity Input:**
    * Enter the quantity for each selected item using a numeric input field (EditText).
    * Ensures accurate calculations for each item.
* **Automatic Calculation:**
    * The app automatically calculates the price for each item by multiplying the quantity with the item price.
    * Displays the subtotal for each item and the grand total for the entire bill.
* **PDF Generation:**
    * Generate professional-looking bills in PDF format.
    * The generated PDF includes details such as item names, quantities, prices, total amount, customer name, and contact information.
* **Save and Share:**
    * Save the generated PDF bill to your device's storage.
    * Share the PDF directly with your customers via email, messaging apps, or other sharing options.
* **Monthly Sales Tracking:**
    * The app keeps track of your total sales for the current month.
    * Displays the monthly sales amount, allowing you to monitor your business performance.
* **Customer Details:**
    * Record customer name and contact number for each bill.
    * This information is included in the generated PDF for record-keeping purposes.
* **Item Removal:**
    * Remove any item from the bill before generating it.
    * This allows you to correct mistakes or modify the bill as needed.
* **Clear Display:**
     * The app displays added items in a list format.

## 🛠️ Tech Stack

* **Android Development:**
    * **Android Studio:** The official Integrated Development Environment (IDE) for Android app development.
    * **Java:** The programming language used to build the app.
* **PDF Generation:**
    * Libraries or APIs for generating PDF documents within the Android environment.
* **UI Components:**
    * **EditText:** For entering customer name, contact number, and item quantities.
    * **Spinner:** For selecting items from a list.
    * **ListView:** For displaying the items added to the bill.
    * **TextView:** For displaying calculated amounts and other information.
    * **Button:** For adding items, generating bills, and other actions.
